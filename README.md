# えいごムシかご (English Beetles)

小学生向けの英単語学習 Web アプリです。ビルド不要の静的サイト（HTML / CSS / JS のみ）として作られています。

## あそびかた

1. **たんご学習タブ**
   - 最初は「きいてみよう」ステージ。英単語の音声（読み上げ）と意味が表示されるだけで、「おぼえた！」を押すとコインがもらえます。
   - 正解を重ねると「いみをえらぼう」（4択クイズ）→「つづりをかこう」（スペル入力）とだんだん難しくなり、難しい問題ほどもらえるコインも増えます。
2. **ムシかごタブ**
   - 学習で貯めたコインを使って、飼っているカブトムシの「おそうじ」「ゼリーをあげる」「つよくする」ができます。
   - ゼリーをあげ続けるとたまご→よう虫→成虫（カブトムシ）に育ち、鍛えるほど見た目も強そうになります。
   - お手入れをさぼるとかごが汚れたり、お腹が空いたりします（クイズに答えるたびに少しずつ減っていきます）。

## 技術構成

- フレームワーク・ビルド不要。`index.html` を開くだけで動作します。
- 単語の発音には ブラウザ標準の Web Speech API (`speechSynthesis`) を使用しています（対応ブラウザが必要です。Chrome 推奨）。
- 進捗（コイン・単語の習熟度・カブトムシの状態）は `localStorage` にブラウザごとに保存されます。

ローカルで確認する場合は、`localStorage` を安定して使うために簡易サーバー経由での起動を推奨します。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 単語を増やす

`words.js` の `WORDS` 配列に `{ en: "...", ja: "..." }` を追加するだけで単語を増やせます（プロトタイプは30語、将来的に1000語まで同じ仕組みで拡張可能です）。
